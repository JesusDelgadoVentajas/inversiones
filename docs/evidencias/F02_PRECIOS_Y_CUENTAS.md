# F02: precios, históricos y cuentas sin credenciales privadas

**Fecha de revisión:** 2026-10-02. **Alcance:** documentación oficial y una consulta local acotada con la clave pública `demo` de EODHD. No hay cuenta personal, prueba desde Cloudflare ni proveedor habilitado en la app. No se guardaron respuestas de mercado.

| Fuente y capacidad | Evidencia | Resultado para esta aplicación |
|---|---|---|
| [EODHD, histórico diario](https://eodhd.com/financial-apis/api-for-historical-data-and-volumes) | Una petición local `GET /api/eod/AAPL.US` con `api_token=demo`, `fmt=json` y rango 2025-10-01 a 2026-10-02 devolvió HTTP 200, 30.436 bytes y 252 barras entre 2025-10-01 y 2026-10-01. Todas tenían cierre positivo y campo `adjusted_close` numérico. | **PROBADO** solo para la forma del histórico de un símbolo de demostración. Es cierre diario, no precio de la sesión en curso. La exactitud de ajustes no se ha contrastado con una fuente independiente. |
| [EODHD Free](https://eodhd.com/pricing) | El proveedor anuncia 20 llamadas al día y hasta un año de histórico EOD para cualquier símbolo con clave personal; la demo se limita a unos pocos símbolos. Su [guía](https://eodhd.com/financial-apis/quick-start-with-our-financial-data-apis) distingue endpoints y costes por llamada. | **DOCUMENTADO** como candidato de histórico internacional. Falta cuenta real, muestreo internacional, fecha de publicación de cada bolsa, Worker y derecho exacto de visualización/caché. No aceptar una demo como prueba de cobertura gratuita universal. |
| [FMP Basic](https://site.financialmodelingprep.com/developer/docs/pricing) | El plan gratuito anuncia 250 llamadas/día para perfil y datos históricos de cierre. Sus cuentas, noticias, cobertura global y tiempo real figuran en planes de pago; la página exige un acuerdo específico para mostrar o redistribuir datos. | **LICENCIA_INSUFICIENTE** para usar sus datos en la interfaz sin un acuerdo adicional; tampoco satisface por sí solo los 20 indicadores y mercados solicitados en Free. Sin consulta de API. |
| [CNMV, índice de información intermedia](https://www.cnmv.es/Portal/consultas/ifi/listaifi?XBRL=S&lang=es&sortDirEmi=1&sortExpEmi=FechaRegistroEntrada) | La CNMV publica informes financieros y XBRL. El 2026-10-02, una petición automatizada local de Node al índice recibió redirección 302 hacia `/portal/Error.aspx`; la sonda la rechazó. Una petición `curl` al mismo URL devolvió 200. | **FALLO_TEMPORAL / acceso programático no demostrado**: no se implementa un scraper ni se infiere que la respuesta de `curl` permita automatización estable. Puede servir como enlace a la fuente oficial; no aporta cotizaciones. |

Las [condiciones de EODHD](https://eodhd.com/financial-apis/terms-conditions) permiten a un usuario no profesional almacenar y analizar datos para fines privados, pero restringen compartir acceso, redistribuir y mostrar la información. El alcance exacto de «mostrar» en un panel exclusivamente del titular debe aclararse antes de integrarlo; esta revisión **no concede permiso de visualización**. La [nota legal de CNMV](https://www.cnmv.es/portal/utilidades/notalegal?lang=es) admite consulta privada, pero no garantiza una interfaz automatizada ni disponibilidad. La [página de FMP](https://site.financialmodelingprep.com/developer/docs/pricing) exige expresamente un acuerdo para mostrar o redistribuir sus datos.

**Conclusión provisional:** hay una ruta técnicamente prometedora para histórico EOD, no para precio intradía reciente ni para una ficha mundial completa. No existe todavía proveedor de precio aprobado, ni evidencia suficiente de cuentas para veinte métricas. G-DATOS y F02.04–F02.07 permanecen abiertos. La siguiente prueba decisiva requiere una cuenta gratuita de EODHD o un candidato con licencia clara, además de Access para repetirla desde un Worker protegido. La consulta local de demostración no autoriza crear un adaptador activo.
